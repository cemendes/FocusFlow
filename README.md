# FocusFlow

A native macOS daily planner and task scheduling application built with SwiftUI.

## Features
- **Daily & Weekly Calendar Views:** Visual time-blocking and drag-and-drop scheduling.
- **Morning & Shutdown Rituals:** Guided routines to start and end your workday intentionally.
- **Task & Project Management:** Markdown-backed task notes and project tracking.
- **Email Task Polling:** Optional Apps Script integration for automated task extraction.

## Building and Running
1. Open `FocusFlow.xcodeproj` in Xcode.
2. Select the `FocusFlow` scheme and target your Mac.
3. Build and run (`⌘R`).
